Si calcola il BMI, ossia l'Indice di Massa Corporea. Questo è dato dal rapporto tra il peso di una persona e la sua altezza in metri elevata
al quadrato. 
Il file index.html contiene un form in cui è possibile inserire il proprio nome, il proprio peso (in kg) e la propria altezza (in cm).
Una volta premuto il tasto "Calcola" i dati vengono inviati al file bmi.php.
Quest'ultimo recupera le variabili dall'HTML, calcola il BMI e, tramite degli if, seleziona a quale fascia BMI la persona appartiene tra le
seguenti:
- sottopeso;
- normopeso;
- sovrappeso;
- obesità.

Una volta associato il BMI alla fascia di appartenenza, viene restituito una card con il nome della persona, il suo peso e la sua altezza,
il suo BMI e la fascia a cui appartiene.
